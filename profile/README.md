# Hi there 👋

### Joining the Organisation
If you need to join the Sanger_LabAutomation organisation, please reach out to [Chris](https://github.com/ChrisH33), [Tobi](https://github.com/tobiajenifuja) or [Kira](https://github.com/KiraNelms). You will need to create a personal GitHub account before you can join, which can be done [here](https://github.com/login).

### Organisation Roles
Organisation roles grant members with the ability to take specific actions or manage some settings without granting full administrative control of Sanger_LabAutomation. You can view the current role assignments under 'Settings > Access > Organisation Roles > Role Assignments'. A summarised table of the predefined responsibilities can be found [here](https://docs.github.com/en/organizations/managing-peoples-access-to-your-organization-with-roles/permissions-of-predefined-organization-roles#permissions-of-predefined-roles)
 - **Owners**: Complete administrative access to Sanger_LabAutomation. This should be limted, but to no less that two people.
 - **Members**: Default role for people in Sanger_LabAutomation. They have a number of permissions, including the ability to create repositories & projects.
 - **Moderators**: In addition to being a member, they are allowed to block & unblock non-member contributors, set limits, and hide comments in public repos owned by the organisation.
 - **Billing Managers**: manage the billing settings of Sanger_LabAutomation; a useful option if we don't have access to billing resources
 - **Security Managers**: Organisation-level role that can be assigned to anyone. Provides access to security alerts and manage security feature, as well as read permission for all repos
 - **Collaborators**: Person with access to one or more Sanger_LabAutomation repositories but is not explicitly a member of the organisation (consultant or temporary employee).
